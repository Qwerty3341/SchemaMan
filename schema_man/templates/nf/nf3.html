{% extends "nf/nf_base.html" %} {% block title %}Third Normal Form{% endblock %} {% block nf_title %}Third Normal Form{% endblock %} {% block nf_subtitle %} No Transitive Dependencies {% endblock %} {% block nf_description %} Third normal form prevents non-key attributes from depending on other attributes that are not the primary key. Put another way, it prevents an attribute from acting like a primary key, without being explicitly declared as one, while other attributes depend on it. This is known as a transitive dependency. {% endblock %} {% block requirements %}
  • The table must be in second normal form.
  • No attribute in the table may depend on another attribute that is not part of the primary key.
