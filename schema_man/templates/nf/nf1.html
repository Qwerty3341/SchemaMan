It states that a table must have a primary key (a PRIMARY KEY column) and must not contain multivalued fields, that is, columns that store multiple values in a single record (for example, a Classes column holding "Biology, Mathematics, Physics" in one field instead of one row per class). {% endblock %} {% block requirements %}
  • The table must have a primary key.
  • The table must not contain repeating groups.
  • The table must not contain multivalued fields.
