In other words, if an attribute depends on only part of the key, it must be moved to a separate table. {% endblock %} {% block requirements %}
  • The table must be in first normal form.
  • If the primary key is simple (a single column), the table automatically satisfies second normal form.
  • If the primary key is composite, look for attributes that depend on only part of the key. Those columns must be moved to a separate table.
