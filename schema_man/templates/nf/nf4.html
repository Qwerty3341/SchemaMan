{% extends "nf/nf_base.html" %} {% block title %}Fourth Normal Form{% endblock %} {% block nf_title %}Fourth Normal Form{% endblock %} {% block nf_subtitle %} No More Than One Multivalued Dependency {% endblock %} {% block nf_description %} Fourth normal form prevents a table from containing more than one multivalued dependency that is independent of the others. A multivalued dependency occurs when, for a single value of one attribute (or set of attributes), there is a set of possible values for another attribute, and that set is independent of the values of a third attribute in the same table. In other words, if a table mixes two separate facts that are not directly related to each other but both depend on the same attribute, it produces repeated, unnecessary combinations that add no new information. {% endblock %} {% block requirements %}
  • The table must be in Boyce-Codd normal form.
  • The table must not contain more than one independent multivalued dependency.
