Alert System

Alert Color Compliant? When is it used? Passes?
Green Pass It's completely verifiable the compliant of the normal form Yes
Yellow Possible violation Used when is not possible to determine with certainty a particular aspect of the normal form Yes
Red Do not pass It is fully verifiable that a table does not satisfy a normal form No
Gray Indeterminable The algorithm does not have sufficient information to evaluate the normal form No

Red and Gray stops the flow of the system meanwhile Green and Yellow continue with the flow.

Dependencies

Functional dependencies and multivalued dependencies by default is not possible to declare them with SQL syntax, so for Schema Man will be declared by a special syntax.

Functional Dependency

--FD: (determinants, ...) -> (dependents)

Multivalued Dependency

--MVD: (determinants, ...) ->> (dependents)
NOTE:
  • Dependencies are very important to detect from second to fourth normal forms
  • The dependencies must be declared inside the corresponding table

Normal forms detection

To detect the normal forms follow the next steps:

  1. Select the engine
  2. Select the level of normalization
  3. Load the SQL
    • You can press the load SQL button to upload a SQL file
    • Can do a drag and drop
    • Or you can write directly the tables
  4. Write the functional and multivalued dependencies
  5. Finally press the run button
